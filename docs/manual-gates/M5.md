# M5 manual gate

Checks that only a human on a real Mac, with the Claude desktop app, can run (CONTRIBUTING.md,
"Rules", rule 2). Run them on the Mac that ran the spike, record the results as a comment on the
pinned Build plan issue, and only then close the milestone and tag its version (docs/design.md,
Appendix A, "Stage 4: milestone gates and tags").

From [#192](https://github.com/weslo/upool/issues/192): a desktop session that ends without
`WorktreeRemove` keeps its slot out of rotation while the app still records it, and its path is
handed to no other session (docs/contracts.md A50). The checks run in order in one Terminal shell,
which holds the variables and functions "Before you start" sets, in a Unity project made for the
gate. They need no Unity Editor. Archive a session with the app's Archive button unless a step
says otherwise. Checks 2 and 3 quit the app, which ends every session in it, a Claude Code session
driving the gate included: run their Terminal steps in Terminal.

## Before you start

**Needs:** the Claude desktop app, with Claude Code 2.1.295 or later; Go; `jq`; the Unity CLI
(1.0.0-beta.13 or later), signed in, and the Unity Editor the spike's project uses; a checkout of
upool on `main` with this gate merged; and a Claude Code session that can call the app's session
tool, which check 1 archives with.

1. **Build upool and put it first on `PATH`,** from the upool checkout:

   ```bash
   upool=$(pwd -P)
   git switch main && git pull --ff-only && make build
   export PATH="$upool/bin:$PATH"
   upool --version
   ```

2. **Make a project for the gate,** at a path no earlier run used: the app keeps its record of a
   worktree by path, and a record an earlier run left would refuse this run's slots (#232's fifth
   run):

   ```bash
   repo=<the spike's Unity project, for its Editor version>
   probe=~/upool-m5-gate-$(date +%Y%m%d%H%M)
   version=$(awk '/m_EditorVersion:/ {print $2}' "$repo/ProjectSettings/ProjectVersion.txt") &&
     unity projects create "$(basename "$probe")" --path ~ --no-cloud --with-pipeline \
       --editor-version "$version" --template com.unity.template.urp-blank &&
     cd "$probe" && printf '/Library/\n/Temp/\n/Logs/\n/UserSettings/\n/obj/\n' > .gitignore &&
     git init -q && git add -A && git commit -qm "Project for the M5 gate" &&
     upool init && sed -i '' 's/^max_slots = 3/max_slots = 6/' .upool && upool status
   cd "$upool"
   record="$HOME/Library/Application Support/Claude/git-worktrees.json"
   recorded() { jq -c --arg p "$probe" '.worktrees[] | select(.path | startswith($p)) |
     {name, path, leasedBy}' "$record"; }
   key=$(jq -r --arg p "$(printf %s "$probe" | tr '[:upper:]' '[:lower:]')" \
     '.repos[] | select(.path == $p) | .key' ~/.upool/registry.json)
   lease() { jq -c --arg s "$1" '.slots[] | select(.name == $s) |
     {state, holder_pid: .lease.holder_pid, session_id: .lease.session_id}' \
     ~/.upool/pools/"$key"/state.json; }
   recorded; lease slot-1
   ```

   **Look for:** `cloned slot-1`, the hooks running `$upool/bin/upool`, slot-1 `ready`, nothing
   from `recorded`, and `lease` printing slot-1 `ready`.

## 1. An archive through the session tool

The session tool's archive of a session whose slot is dirty runs no `WorktreeRemove` and keeps the
app's record (A28). This checks that the reclaim keeps the slot, that no other session is handed
it, and that `doctor` says how to free it (A50).

1. **Start a desktop worktree session** in `$probe`, noting the time first, with the prompt
   `Create an empty file named m5-dirty.txt with the Bash tool, then run git status --short. Do
   nothing else.`:

   ```bash
   since=$(date '+%Y-%m-%d %H:%M:%S')
   ```

2. **Archive it through the app's session tool,** not with the Archive button: from the other
   Claude Code session, ask for the session to be archived with the session tool (its
   `archive_session`). Then:

   ```bash
   awk -v since="$since" 'substr($0, 1, 19) >= since' ~/Library/Logs/Claude/main.log |
     grep -E 'Archived session|Cleaning up worktree|Removing worktree|hook-based worktree'
   (cd "$probe" && upool status); recorded
   (cd "$probe" && upool take gate-m5-take --no-create); echo "take exited $?"
   (cd "$probe" && upool release gate-m5-take)
   (cd "$probe" && upool doctor --json) |
     jq -c '.data.checks[] | select(.name | startswith("slot-"))'
   ```

   **Look for:**
   - `Archived session` and none of the cleanup lines, as A28 has it;
   - the session's slot, slot-N, `leased`, and the app's record still naming it;
   - from `take`, `not reclaiming slot-N, though its holder, process <pid>, is gone: the desktop
     app still records it for session local_<id>, as its worktree <name>`, and no `reclaimed
     slot-N`. `take` hands out another free slot, such as the one the first session's top-up
     cloned, which `release` gives back, or with none exits 1; never slot-N;
   - from `doctor`, slot-N's `warn` with the same reason.

   If the slot is not `leased`, or the app ran the cleanup, this app version archives through its
   session tool as the Archive button does: record that, and the check shows nothing of the fix.

3. **Start a second desktop worktree session** in `$probe` with `pwd`:

   ```bash
   awk -v since="$since" 'substr($0, 1, 19) >= since' ~/Library/Logs/Claude/main.log |
     grep -E 'hook-based worktree|worktree_hook_failed'
   (cd "$probe" && upool status)
   ```

   **Look for:** the session started in a slot other than slot-N, its `pwd` that slot, and no
   `worktree_hook_failed`. Archive it.

4. **Free slot-N** as `doctor` says: unarchive the first session from the app's archived sessions,
   open it, and archive it with the Archive button. Then:

   ```bash
   (cd "$probe" && upool status); recorded
   (cd "$probe" && upool doctor --json) | jq -c '.data.checks[] | select(.name == "slot-N")'
   ```

   **Look for:** slot-N `parked`, with `m5-dirty.txt` kept; no record of it; and no `not
   reclaiming` warning on it.

## 2. A quit, a Terminal take and a resume

Quitting the app ends its sessions' processes without `WorktreeRemove`, and keeps their records
for a resume (#192's step 1). This checks that a dead-PID reclaim no longer hands such a slot to
another holder, and that the resumed session keeps its slot (A50).

1. **Start a desktop worktree session** in `$probe` with `pwd`, and note the slot it prints,
   slot-M. Quit the app with ⌘Q, which ends this gate's other session too, relaunch it, and do not
   open the session. Then, from Terminal:

   ```bash
   (cd "$probe" && upool status); recorded
   (cd "$probe" && upool take gate-m5-quit --no-create); echo "take exited $?"
   (cd "$probe" && upool status)
   ```

   **Look for:** slot-M `leased` and recorded; from `take`, `not reclaiming slot-M`, then either
   another free slot handed out or `take exited 1`; and slot-M still `leased`, its lease the
   session's.

2. **Resume the session** with the prompt `Run pwd and git status --short --branch with the Bash
   tool. Do nothing else.`, then:

   ```bash
   (cd "$probe" && upool status --json) |
     jq -c '.data.pools[0].slots[] | {name, state, holder: .lease.holder}'
   ```

   **Look for:** slot-M's path, `## HEAD (no branch)`, not `gate-m5-quit`, and slot-M still
   `leased`. Archive the session; slot-M becomes `needs-reset`. Release the Terminal take's slot if
   it got one: `(cd "$probe" && upool release gate-m5-quit)`.

## 3. The create hook reads the app's record

The create hook runs in the desktop app's helper, which under `~/Documents` could not open a
repository's files (docs/contracts.md (a)). The app's record is outside `~/Documents`, so the hook
should read it, but only this shows it (A50).

1. **Start a desktop worktree session** in `$probe` with `pwd`, note its slot, slot-K, quit the
   app, relaunch it, and do not open the session. Then release the slot from Terminal, as a person
   may, its holder gone, so that it is `ready` while the app still records it:

   ```bash
   (cd "$probe" && upool release "$probe/.claude/worktrees/slot-K" && upool status); recorded
   ```

   **Look for:** slot-K `ready`, and the record still naming it. The create hook hands out the
   first `ready` slot in `status`'s order, so slot-K must be first, with another `ready` slot after
   it: take any `ready` slot listed before it with `(cd "$probe" && upool take gate-m5-fill-1)`,
   and so on, and run `(cd "$probe" && upool refresh)` if none is `ready` after it.

2. **Start a new desktop worktree session** in `$probe` with `pwd`, noting the time first:

   ```bash
   since=$(date '+%Y-%m-%d %H:%M:%S')
   # start the session, then:
   awk -v since="$since" 'substr($0, 1, 19) >= since' ~/Library/Logs/Claude/main.log |
     grep -E 'hook-based worktree|worktree_hook_failed'
   (cd "$probe" && upool status)
   ```

   **Look for:** the session started, its `pwd` a slot other than slot-K, and no
   `worktree_hook_failed`; slot-K still `ready`. A refusal naming slot-K means the hook could not
   read the record from the helper: record the log lines.

**Afterwards:** archive both sessions, the one from step 1 first, and release each
`gate-m5-fill-*` slot.

## 4. A desktop /clear

A desktop `/clear` starts a new session in the same slot, its startup carrying a new `session_id`,
so upool finds the slot by `cwd` alone. No capture says whether it runs in the same CLI process.
upool takes up the lease either way: as one its own process holds, or as its session's lease
whose holder has ended. It takes up no other holder's (A50). Only this shows which.

1. **Start a desktop worktree session** in `$probe` with `pwd`, and note its slot, slot-J. Then:

   ```bash
   lease slot-J
   ```

   **Look for:** slot-J `leased`, with a `holder_pid` and a `session_id`. Note both.

2. **Run `/clear` in the session,** then send `pwd`. Then:

   ```bash
   lease slot-J
   ps -o pid=,command= -p <holder_pid>
   ```

   **Look for:** slot-J still `leased`; the `session_id` a new one; and `ps` listing the
   `holder_pid`, the session's live CLI. Record whether `holder_pid` changed: unchanged, the
   `/clear` ran in the same process; changed, it started a new one. A `session_id` left as it was
   means the startup did not take the lease up: record it as a failure. Archive the session.

**Afterwards:** take upool out of the project and move it to the Trash:

```bash
(cd "$probe" && upool deinit --yes)
unity projects remove "$probe" --force
mv "$probe" ~/.Trash/
recorded
```

**Look for:** `deinit` removing each slot, and nothing from `recorded`. A slot `deinit` refuses
as parked holds `m5-dirty.txt` from check 1: remove it as `deinit` says.
