# M7 manual gate

Checks that only a human on a real Mac, with the Claude desktop app, can run (CONTRIBUTING.md,
"Rules", rule 2). Run them on the Mac that ran the spike, record the results as a comment on the
pinned Build plan issue, and only then close the milestone and tag its version (docs/design.md,
Appendix A, "Stage 4: milestone gates and tags").

From [#286](https://github.com/weslo/upool/issues/286): the desktop app runs upool's create hook
through its helper, `Claude.app/Contents/Helpers/disclaimer`, so macOS asks about upool itself,
by its resolved path, whether it may access the Documents folder, and holds the hook's git until
someone answers (docs/contracts.md (a), the "Process running the hook" row). `upool init`, as its
last step, and `upool doctor`, in its `documents-access` check, have the helper run the create
hook's dry run, so that the prompt comes up while someone is at the keyboard; the check warns while
it is open and passes once it is allowed. The fakes cover the check's outcomes and the hook's wait;
only a real Mac shows the prompt, its log lines and its answer. The checks run in order in one
Terminal shell, which holds the variables "Before you start" sets, in a Unity project made for the
gate under `~/Documents`.

The issue asks for the prompt to be raised again after `tccutil reset SystemPolicyDocumentsFolder`
for the app's bundle id. The benchmark's log shows that macOS asks about upool's binary by its
path, not about the app, and `tccutil` resets a decision only by bundle id, or every app's at once.
So the gate runs a upool at a path no earlier run used, which macOS has made no decision for, and
leaves every other decision alone.

## Before you start

**Needs:** the Claude desktop app, logged in; Go; `jq`; the Unity CLI (1.0.0-beta.13 or later),
signed in, and the Unity Editor the spike's project uses; and a checkout of upool on `main` with
#286 merged. Be at the Mac's screen: the checks wait on a prompt.

1. **Build upool and put it at a new path, first on `PATH`,** outside `~/Documents`, from the upool
   checkout:

   ```bash
   upool=$(pwd -P)
   git switch main && git pull --ff-only && make build
   gate=~/upool-m7-gate-$(date +%Y%m%d%H%M)
   mkdir -p "$gate/bin" && cp bin/upool "$gate/bin/upool"
   export PATH="$gate/bin:$PATH"
   command -v upool; upool --version
   tcc='subsystem == "com.apple.TCC" AND (eventMessage BEGINSWITH "AUTHREQ_PROMPTING: "'
   tcc="$tcc"' OR eventMessage BEGINSWITH "AUTHREQ_RESULT: ")'
   prompts() { log show --last "$1" --style compact --predicate "$tcc" |
     grep -E "SystemPolicyDocumentsFolder|AUTHREQ_RESULT: msgID=${2:-none}," || true; }
   ```

   `prompts <window> [<msgID>]` prints the Documents prompts TCC logged within the window, and the
   result of the request `msgID` names. Note the desktop app's version (Claude → About Claude).

   **Look for:** `command -v upool` printing `$gate/bin/upool`, which no earlier run used.

2. **Make a project for the gate under `~/Documents`,** at a path no earlier run used, as a git
   repository with its first commit, but do not run `upool init` yet:

   ```bash
   repo=<the spike's Unity project, for its Editor version>
   probe=~/Documents/upool-m7-gate-$(date +%Y%m%d%H%M)
   version=$(awk '/m_EditorVersion:/ {print $2}' "$repo/ProjectSettings/ProjectVersion.txt") &&
     unity projects create "$(basename "$probe")" --path ~/Documents --no-cloud \
       --with-pipeline --editor-version "$version" --template com.unity.template.urp-blank &&
     cd "$probe" && printf '/Library/\n/Temp/\n/Logs/\n/UserSettings/\n/obj/\n' > .gitignore &&
     git init -q && git add -A && git commit -qm "Project for the M7 gate"
   ```

   **Look for:** the project made, and no Unity Editor left open on it.

## 1. `upool init` raises the prompt as its last step, and `upool doctor` reports it pending

1. **Run `upool init`** in the project, and **do not answer the prompt** that comes up:

   ```bash
   cd "$probe" && upool init; echo "init exited $?"
   prompts 10m
   ```

   **Look for:** `cloned slot-1`, the hooks running `$gate/bin/upool`, and, right after the hooks'
   line, a macOS prompt asking whether upool may access files in your Documents folder, still on
   the screen. Note its exact words. About 10 s later, `init exited 0`, after a warning on stderr,
   `upool: warning: documents-access: macOS is asking whether upool may access Documents; answer
   it, then run upool doctor again`; and from `prompts`, one `AUTHREQ_PROMPTING` line with
   `service=kTCCServiceSystemPolicyDocumentsFolder` and `subject=Sub:{$gate/bin/upool}`, written
   out in full. Note its `msgID`, as `id=<msgID>`. A subject naming the app instead, such as
   `com.anthropic.claudefordesktop`, means the app's build runs the hook differently: record it,
   and the rest of the gate is moot.

2. **Run `upool doctor`** with the prompt still open:

   ```bash
   upool doctor; echo "doctor exited $?"
   prompts 10m "$id"
   ```

   **Look for:** the last line `warn  documents-access  macOS is asking whether upool may access
   Documents; answer it, then run upool doctor again`, about 10 s after the line before it;
   `doctor exited 0` unless another check failed; and from `prompts`, still the one prompt line,
   with no `AUTHREQ_RESULT` line for its `msgID`.

## 2. `upool doctor` passes once the prompt is answered

1. **Allow the prompt,** then run `upool doctor` again:

   ```bash
   upool doctor; echo "doctor exited $?"
   prompts 15m "$id"
   ```

   **Look for:** the last line `pass  documents-access  the desktop app's helper ran upool's
   create hook, and its git read <probe> in <n> ms`, with `<n>` well under a second; and from
   `prompts`, an `AUTHREQ_RESULT: msgID=<id>, authValue=2` line, the answer, after the prompt's.
   System Settings → Privacy & Security → Files and Folders now lists upool, with Documents
   Folder on.

## 3. A desktop session then starts within the clone time

1. **Start a desktop worktree session** in `$probe`, noting the time first, with the prompt
   `Run pwd with the Bash tool. Do nothing else.`:

   ```bash
   date '+%Y-%m-%d %H:%M:%S'
   ```

   **Look for:** the session started in `$probe/.claude/worktrees/slot-1` within a few seconds,
   its `pwd` that slot, and no macOS prompt; and in `~/Library/Logs/Claude/main.log`, after the
   noted time, `Created hook-based worktree … at <probe>/.claude/worktrees/slot-1` with its
   `worktree=` time well under the 26 s a clone takes (docs/design.md, "Why clone the whole
   checkout rather than check out and clone the Library"), and no `WorktreeCreate hook failed`
   line.

2. **Archive the session** with the app's Archive button.

## Clean up

```bash
cd ~ && (cd "$probe" && upool deinit --yes)
```

**Look for:** `deinit` removing slot-1 and the pool. Then delete `$probe` and `$gate`. The privacy
decision for `$gate/bin/upool` stays in System Settings → Privacy & Security → Files and Folders
until you remove it there; no later run uses that path.
