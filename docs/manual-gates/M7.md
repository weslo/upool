# M7 manual gate

Checks that only a human on a real Mac, with a real Unity Editor, can run (CONTRIBUTING.md,
"Rules", rule 2). Run them on the Mac that ran the spike, record the results as a comment on the
pinned Build plan issue, and only then close the milestone and tag its version (docs/design.md,
Appendix A, "Stage 4: milestone gates and tags").

From [#287](https://github.com/weslo/upool/issues/287), one of the first benchmark's follow-ups:
the RAM budget charges an Editor by its mode, `editor_ram_gb_gui` (default 6) or
`editor_ram_gb_headless` (default 2.5), against `editor_ram_budget_gb`, and a refusal names the
limit and the charge (docs/contracts.md (h); A9 as amended). The fake `unity` shows that a refused
open launches nothing and that an admitted one is charged by its mode; only real Editors show that
the refusal comes before a GUI Editor's window does, and that the two Editors the budget admits run
side by side. The check runs in one Terminal shell, which holds the variables "Before you start"
sets, in a Unity project made for the gate. It needs no Claude desktop app.

## Before you start

**Needs:** Go; `jq`; the Unity CLI (1.0.0-beta.13 or later), signed in, and the Unity Editor the
spike's project uses; and a checkout of upool on `main` with #287 merged. No other Unity Editor
may be open: the check counts the Editors `unity status` lists. None of `editor_ram_budget_gb`,
`editor_ram_gb`, `editor_ram_gb_gui`, `editor_ram_gb_headless`, `helper_ram_gb`, `max_editors` and
`max_cold_imports` may be set in `~/.config/upool/config.toml` or a `UPOOL_*` variable: the check
sets the two it needs in its shell, and the rest keep their defaults.

1. **Build upool and put it first on `PATH`,** from the upool checkout:

   ```bash
   upool=$(pwd -P)
   git switch main && git pull --ff-only && make build
   export PATH="$upool/bin:$PATH"
   upool --version
   grep -E 'ram|editors|cold' ~/.config/upool/config.toml 2>/dev/null || echo "no overrides"
   env | grep '^UPOOL_' || echo "no UPOOL_ variables"
   ```

   **Look for:** `no overrides` and `no UPOOL_ variables`.

2. **Make a project for the gate,** at a path no earlier run used, with a pool, and take two slots
   (the second `take` clones its slot, about 26 s):

   ```bash
   repo=<the spike's Unity project, for its Editor version>
   probe=~/upool-m7-budget-$(date +%Y%m%d%H%M)
   version=$(awk '/m_EditorVersion:/ {print $2}' "$repo/ProjectSettings/ProjectVersion.txt") &&
     unity projects create "$(basename "$probe")" --path ~ --no-cloud --with-pipeline \
       --editor-version "$version" --template com.unity.template.urp-blank &&
     cd "$probe" && printf '/Library/\n/Temp/\n/Logs/\n/UserSettings/\n/obj/\n' > .gitignore &&
     git init -q && git add -A && git commit -qm "Project for the M7 gate" &&
     upool init && upool status
   cd "$upool"
   unset UNITY_PROJECT_PATH
   s1=$(cd "$probe" && upool take gate-budget-1)
   s2=$(cd "$probe" && upool take gate-budget-2)
   echo "$s1"; echo "$s2"; unity status --format json | jq -c '.data.instances'
   ```

   **Look for:** two slot paths, and `unity status` listing no Editor (`[]` or `null`). If it lists
   one, close it and run the last line again.

## 1. A budget of 10 GB refuses a second GUI Editor at 6 GB, and admits it at 2.5 GB

From [#287](https://github.com/weslo/upool/issues/287). With `editor_ram_budget_gb` 10 and the
default charges, one GUI Editor is charged 2 + 6 = 8 GB, and a second would take the charge to
14 GB, so the budget refuses it, naming itself and the charge, before anything is launched.
`max_editors`, derived at the smaller charge, is 2 here, floor((10 − 2 − 2) / 2.5), so the refusal
is the budget's. With `editor_ram_gb_gui` 2.5, two GUI Editors are charged 2 + 2.5 + 2.5 = 7 GB,
and both open. A charge is set when its Editor is admitted, so the first Editor is opened again
under the new setting.

1. **Open the first slot's Editor with its window,** under a budget of 10 GB:

   ```bash
   export UPOOL_EDITOR_RAM_BUDGET_GB=10
   (cd "$s1" && upool open --gui; echo "exit $?")
   (cd "$probe" && upool status)
   jq -c '.editors[] | {project, mode, charge_gb}' ~/.upool/editors.json
   ```

   **Look for:** `opened slot-1's Editor gui, process <pid>: ready, charged 6.0 GB`, then
   `exit 0`; the Editor's window; in `upool status`, after the slots, the line
   `slot-1's Editor: gui, process <pid>, charged 6.0 GB`; and one ledger entry, `"mode":"gui"` and
   `"charge_gb":6`.

2. **Try the second,** and check that nothing was launched for it:

   ```bash
   (cd "$s2" && upool open --gui; echo "exit $?")
   unity status --format json | jq -c '[.data.instances[]? | .projectPath]'
   pgrep -fl 'Unity.app/Contents/MacOS/Unity'
   ```

   **Look for:** at once, `upool: opening the Editor of <s2>: editor_ram_budget_gb refuses another
   Editor, a gui one charged 6.0 GB: the Editors would be charged 14.0 GB, over its 10.0 GB`, then
   `exit 1`; no second window; `unity status` listing `$s1` alone; and no Unity process with `$s2`
   in its arguments.

3. **Set the GUI charge to 2.5 GB, open the first Editor again under it, then open the second:**

   ```bash
   (cd "$s1" && upool close)
   export UPOOL_EDITOR_RAM_GB_GUI=2.5
   (cd "$s1" && upool open --gui; echo "exit $?")
   (cd "$s2" && upool open --gui; echo "exit $?")
   (cd "$probe" && upool status)
   unity status --format json | jq -c '[.data.instances[]? | {projectPath, state}]'
   ```

   **Look for:** each `open` printing `ready, charged 2.5 GB` and `exit 0`; two windows;
   `upool status` listing `slot-1's Editor` and `slot-2's Editor`, each `gui` and `charged 2.5 GB`;
   and `unity status` listing `$s1` and `$s2`, both `ready`.

A second Editor launched in step 2, a refusal that names no limit or no charge, or a second open
refused in step 3, fails this check.

## Clean up

```bash
(cd "$s1" && upool close); (cd "$s2" && upool close)
(cd "$probe" && upool release gate-budget-1 && upool release gate-budget-2)
unset UPOOL_EDITOR_RAM_BUDGET_GB UPOOL_EDITOR_RAM_GB_GUI
(cd "$probe" && upool deinit --yes)
```

**Look for:** both Editors closed, both slots released, an empty `editors` list in
`~/.upool/editors.json`, and `deinit` removing the slots and the pool. Then delete `$probe`.
